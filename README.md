# CRM Demo Project

PHP + MySQL based CRM demo project with login and user management.

## Features
- Login / Logout
- Add, edit and view users

## Setup
1. XAMPP install karo aur is folder ko `crm` naam se `htdocs` mein rakho (`C:\xampp\htdocs\crm`).
2. `localhost/phpmyadmin` kholo aur naya database banao (jaise `crm_db`).
3. Is database mein `crm_db.sql` file import karo.
4. `app` folder mein database connection file mein apne DB ki details check karo.
5. Browser mein `localhost/crm/public/login.php` kholo.
